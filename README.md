# homebrew-tap

Homebrew casks and formulae for [imkkapoor](https://github.com/imkkapoor)'s apps.

```
brew tap imkkapoor/tap
brew install --cask <name>
```

Or in one step: `brew install --cask imkkapoor/tap/<name>`.

| Name                           | Type | What it is                                                                 |
| ------------------------------ | ---- | -------------------------------------------------------------------------- |
| [tungsten](Casks/tungsten.rb)  | Cask | [Tungsten](https://www.tungsten.wtf/), a pan/zoom canvas of terminal panes. Apple Silicon. Updates itself. |
